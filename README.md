# Litigation Support

A website to help people with litigation and self-representation.

## Status

Phase 0: setup done. Next: research and planning.

## Layout

- `docs/research/` — research notes (law, users, competitors)
- `docs/planning/` — scope, features, roadmap
- `docs/decisions/` — short records of key choices
- `src/` — app code (stack not chosen yet)

## Important

This site gives legal information, not legal advice. Keep real case data out of git.
